DBeaver Text → Markdown Converter

Paste DBeaver query output and get a clean Markdown table with live preview.

Column type indicators — add these to your column headers to control number formatting:
Integer  (i) Whole numbers with thousands commas.
e.g. Revenue (i) → 1,234,567
Decimal  (d) or (d,n) Floats with commas & n decimal places (default 2).
e.g. Price (d,3) → 1,234.500
Plain column No indicator — value is output as-is.
e.g. Name → Alice
Indicators are stripped from the output table header automatically.
